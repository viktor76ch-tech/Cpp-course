Массив (Array) - это набор переменных одного типа в НЕПРЕРЫВНОЙ ОБЛАСТИ ПАМЯТИ.
Массивы бывают:
1. Динамические и Статические;
Количество элементов статического массива может быть задана целочисленным констрантным
значением на этапе написания кода. Размер статического массива не возможно изменить 
после компиляции. Размер диинамического массива может быть задан переменным значением
на этапе выполнения прогриммы. Предварительно это переменное значение можно вычислить
или ввести с клавиатуры.
Как статические, так и динамичекие массивы бывают
2. Одномерные, двумерные, трехмерные....... многмерные;
Количество измерений массива ничем не ограничевается.

Массивы объявляются следующим образом:
type name[SIZE];
type - тип элементов массива;
name - имя массива. 
	   Для именования массивов используются такие же 
	   идентификаторы, как и для именования переменных.
SIZE - количество элементов массива, может быть задано лишь 
	   целочисленным константным значением;

	   Обычно массивы объявляют так:
	   const int n = 5;
	   int arr[n];

Обращение к элементам массива. Для того чтобы обратиться к элементу массива нужно указать
его номер в квадратных скобках после имени массива. К элементам массива, так же как и 
обычним переменным можно обращаться на чтение и на запись.
arr[1] = 1024;			//обращаемся к элементу массива на запись
cout << arr[1] << endl;	//образаемся к элементу массива на чтение
Элементы массива нумеруются с  нуля, именно по этому номер последнего элемента всегда
на еденицу меньше, чем количество элементов, т.е в массиве из 5 элементов отсутсвует
пятый элемент.
Для обращения к элементам массива очень удобно использовать цикл FOR, поскольку у него 
есть счетчик i, который можно задавать в качестве номера элемента.
Инициализация.
При объявлении массива его элементы заполнены мусором, для того чтобы убрать из массива
мусор, его нужно проинициализировать. Для инициализации массива нужно перечислить значения
его элементов в фигурных скобках через запятую. int arr[n] = { 3, 5, 8 };
Элементы, которые не указаны при инициализации, получают значения по умолчанию, для 
числовых значений это ноль.


Генерация случайных чисел
Для генерации случайного числа можно использовать функцию rand()
Функция rand() возвращает псевдослучайное число от 0 до 32767 
Это случайное число можно вывести на экран, сохранить в переменную
или в элемент массива.
Для того, чтобы ограничить диапазон генерации случайных чисел с верху
используется операция остаток от деления, потому что остаток от деления
всегда строго меньше делителя. Для того чтобы ограничить диапазон генерации
случайных чисел с низу используется операция сложения. 

Двумерные массивы
Если одномерные массивы - это набор значений в непрерывной области памяти, 
которые визуально представляют строкой, то двумерные массив - это таблица 
однотипных значений в непрерывной области памяти. Как и в любой другой таблице,
у двумерного массива есть строки и столбики. Столбики часто  называют элементами
строки. Как строки, так и элементы строки нумеруются с нуля.
При объявлении массива сразу указывают количество строк потом количество элементов
строки. Размеры так же задаются целочисленным константным значением.
Для обращения к элементам двумерного массива очень удобно использовать вложенные
 циклы. Как правило, основной цикл перебирает строки, а вложенный - элементы строки
 (столбики).
