Функции
Функция - это именнованая последовательность выражений и других конструкций языка с++,
реализующая определенный алгоритм (возведение числа в степень, вывод массива на экран,
сортировка массива, поиск максимального и минимального значения, поиск файла на диске,
 установление сетевого соединения).
 Функции позволяют сделать код более логичным понятным и читаемым. Так же функции поз-
 воляют исходный код программы разместить в нескольких исходных файлах, что позволяет
 множеству программистов работать над одной программой. Функции в других языках програм
 мирования еще называют процедурами.
 Прежде чем использовать фукцию, её нужно объявить и написать следующим образом:

 type name (parameters)
 {
	.......;
	group-of-statements;
	.......;
 }

 type - тип возвращаемого значения. Любая функция по завершении возвращает какое либо
 значение - результат своей работы. Любое значение в языке с++ имеет тип. Этот тип и 
 указывается при объявлении и написании функции. Функция может вернуть значение любого
 существующего типа.
 Есть функции, которые не возвращают никаких значений, поскольку результат их работы 
 и так виден, например - когда функция выводит что-то на экран, или меняет какие либо 
 значения в памяти, проверить это можно другой функцией, которая выводит значения на
 экран. Тип возвращаемого значения таких функций - void(пустота).
 Если тип возвращаемого значения отличен от void, то в ее теле обязательно должно быть
 написано ключевое слово return с возвращаемым значением. Ключевое слово return прерывает
 работу функции, возвращает значение на место вызова и возвращает управление на место
 вызова. Void- функциях ключевое слово return писать не обязательно, но его можно испо-
 льзовать, для того, чтобы прервать работу функции при некоторых обстоятельсвах. В void -
 функциях return пишется без значения, просто return и ";". Ключевое слово return может
 верноуть только одно значение или вообще не возвращать никаких значений.
 name -  имя функции. Для именования функции используются такие же идентификаторы, как и
 при именовании переменных.
 parameters - это список принимаемых параметров функции. Принемаемые параметры - это 
 исходные данные для работы функции. Принимаемые параметры - это самые обычные переменные,
 объявленные в заголовке функции. Эти переменные являются для своей функции, то есть они 
 удаляются из памяти по завершении функции. Принимаемые параметры доступны только в нутри
 своей функции.
 Group of statements - это тело функции, которое реализует алгоритмы возложенные на функции.
 В теле функции можно писать все, что угодно, кроме реализации другой функции.

 Прототип, реализация, вызов.
 Прототип функции (Объявление функции - Function declaration) состоит из заголовка функции
 и заканчивается ";". Нужен для того, чтобы имя функции, ее список принимаемых параметров
 и тип возвращаемого значения были известны на момент вызова.
 Реализация функции (Определение функции - Function definition) состоит из заголовка и тела 
 функции и определяет, что делает функция.
 Для того, чтобы функция хотя бы раз отработала, ее нужно хотя бы раз вызвать. Один раз
 написанная функция может быть вызвана склько угодно раз. Это позволяет в значительной
 степени сократить объем исходного кода, сохранив при этом функционал программы.
 Основным приимуществом функций является то, что они ведут к повторному использованию
 кода, а повторное использование кода - это то, к чему стремится программирование, сколько
 оно существует.

 Принимаемые и передаваемые параметры.
 Когда мы пишем прототип или реализацию функции мы показываем, какие параметры функция 
 принимает. Когда мы вызываем функцию, мы передаем в нее параметры.
 В функцию можно передать ровно столько параметров, сколько она принимает. В противном 
 случае выходят ошибки:
 Too few arguments in function call - если в функцию передать меньше параметров,
 чем она принимает;
 Too many arguments in function call - если в функцию передать больше параметров, 
 чем она принимает;
 Function doesn't take 'N' arguments;
 Но в функцию можно передать меньше параметров, чем она принимает, благодаря параметрам
 про умолчанию.
 Параметры по умолчанию (Default parameters).
 Это параметры, у которых есть значения по умолчанию.
 int Sum(int a, int b, int c = 0);
 Значения по умолчанию даются параметрам при объявлении функции. Значения по умолчанию
 должны быть последними, но не в начале или в середине. В противном случае компилятор
 на сможет понять какой параметр и куда передать. Обсолютно все параметры функции могут
 иметь значение по умолчанию, в таком случае функция может быть вызвана вообще без 
 параметров. Параметры по умолчанию нужно писать только в прототипе функции, в противном
 слочае возникает ошибка компилятора:
 Redefinition of default parameter.

 Unresolved Externals
 Ошибка на этапе компановки LNK2019: unresolved external symbol found возникает в том 
 случае, когда список принимаемых параметров в прототипе и реализации функции отличается.
 Тогда компановщик не может найти и связать прототип и реализацию.

 Передача массива в функцию.

 void FillRand(int arr[], const int n)
 Для того, чтобы показать, что принимаемый параметр- массив, после имени параметра пишут
 [], кроме самого массива функция в обязательном порядке принимает размер этого массива.
 И того, любая функция, работающая с массивом, принимает как минимум два параметра - массив
 и его размер.

 Перегрузка функций
 Перегрузкой функций, называется сетуация, при которой есть две и более функции с одинаковым
 именем, но разным списком принимаемых параметров. Список принимаемых параметров перегру-
 женных функций может оличаться как типом, так и количеством аргументов. Тип возвращаемого
 значения так же может отличаться, но перегруженные функции не могут отличаться лищь типом
 возвращаемого значения, поскольку компилятор определяет, какой экземпляр перегруженной
 функции вызвать по списку принимаемых параметров, а не по возвращаемому  значению.
 Реализации перегруженных функций могут отличаться или быть иденьтичными. Как правило, если
 список принимаемых параметров перегруженных функций отличается лишь типом, реализации
 таких функций будут идентичными или очень похожими. Но если список принимаемых параметров
 перегруженных функций отличается количеством аргументов, то скорее всего и реализации 
 этих функций будут разными.
 Если функция не умеет работать с каким либо типом данных, то ее нужно перегрузить для 
 этого типа данных.

 Шаблоны функций
 Шаблонной называетсяя функция, которая может работать с любым типом данных. Для тогоБ
 чтобы сделать функцию шаблонной, перед ней нужно просто создать шаблон следующим образом:
 template<typename T>. 
 Ключевое слово template - создает шаблон.
 Ключевое слово typename - создает шаблоный тип. Шаблонных типов может быть сколько угодно
 Т - имя шаблонного типа.
 После создания шаблона, любой принимаемый параметр, возвращаемое значени и локальная
 переменная могут быть шаблонного типа.
