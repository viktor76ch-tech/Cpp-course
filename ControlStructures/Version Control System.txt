Система контроля версий (VCS - Version Control System.) - это программа, которая сохраняет 
промежуточные версии исходных кодов в контрольных точках, и позволяет в любой момент
возвращаться к этим контрольным точкам. На сегодняшний день существует множество систем
контролья версий, например:
SVN
Subversion
Mercurial
......
......
но коронное место занимает Git, поскольку он позволяет использовать платформу GitHub.
Сразу же следует сказать, что Git и GitHub - это не одно и то же.
Git - это система контроля версий;
GitHub - это облачное хранилище;

Ключевым понятием любой системы контроля версий является репозиторий:
Repository - это хранилище исходных кодов.
Различают локольный и удаленный репозитории.
Local repository хранится на ПК программиста;
Remote repository на сервере - GitHub;

Локальный и удаленный репозитории сихронизируют при помощи команд fetch, pull, push.
fetch - скачивает но НЕ распаковывает изменения с удаленного репозитория на локальный;
pull  - скачивает и распаковывает изменения с удаленного репозитория на локальный;
push  - отправляет изменения с локального репозитория на удаленный;

COMMIT - это контрольная точка, в которую сохраняются изменения; COMMIT всегда создается
в ручную и для его создания программист обязан написаить Commit message, который 
описывает изменения внесенные в репозиторий. Commit message должен осознанно написать
человек и этот процесс никак нельзя автоматизировать. Так же Commit - это минимальная
еденица обмена данными между локальным и удаленным репозиториями. Если на удаленный 
репозиторий нужно отправить один файл, то для этого файла создается Commit  и уже он 
отправляется на удаленный репозиторий.
